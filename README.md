# GoDCP

Проект приложения для работы с файлом карты портов DCP компьютера Sprinter 2000.

Настольный редактор на Go + Fyne для Windows, Linux и macOS. Загруженный BIN
является источником всех назначений. Версию карты выбирает пользователь;
приложение проверяет размер файла, а справочник использует для подписей кодов.

## Текущее состояние

Первая версия предоставляет пять вкладок:

- **Редактор карты** — таблица и HEX, замена байтов, Undo/Redo и сохранение.
- **Назначенные порты** — ненулевые назначения с фильтрами и раскрытием 128 алиасов.
- **По внутреннему порту** — все внешние адресные группы и режимы для кода.
- **По внешнему порту** — назначения адреса во всех 32 сочетаниях режимов.
- **Генератор BIOS** — копируемые `HL / DE / B` или `DW / DW / DB`
  в двоичной записи с группировкой BIOS. Генератор не изменяет карту.

Поддерживаются русский и английский интерфейс, светлая/тёмная/системная тема,
перетаскивание BIN в окно и запуск с путём к файлу. Редактор и поиски используют
общий текущий документ, включая несохранённые изменения. Неизвестные коды
сохраняются без преобразований. Длина файла всегда остаётся 16 384 байта.

Результаты изучения файлов, проверенные свойства дампа и открытые вопросы
собраны в [обзоре исходных материалов](docs/INITIAL_SURVEY.md).
Порядок работы и зависимости описаны в [руководстве](docs/USER_GUIDE.md),
устройство приложения — в [описании архитектуры](docs/DESIGN.md).
Измеренные результаты и границы проверки — в [отчёте проверки](docs/VALIDATION.md).

## Сборка и запуск

Нужны Go и платформенные зависимости Fyne, включая C-компилятор.
На Windows используется GCC из MSYS2. Скрипты выполняют тесты и нативную сборку:

```powershell
# Windows
.\scripts\build.ps1
.\Build\GoDCP.exe .\Example\DCP_PAGE.bin
```

```sh
# Linux / macOS
bash scripts/build.sh
./Build/GoDCP ./Example/DCP_PAGE.bin
```

В данном рабочем окружении Windows скрипт также обнаруживает переносимый Go
в `%LOCALAPPDATA%\GoDCP-tools`. На другом компьютере установите Go в PATH
или задайте путь через `-Go` (PowerShell) / `GO` (Bash). Подробности — в руководстве.

```sh
go test ./...
```

Тесты проверяют адресацию, алиасы, маски BIOS, точное сохранение BIN, Undo/Redo
и взаимодействия GUI через программный драйвер Fyne. Workflow GitHub Actions
предусматривает три ОС; его фактический результат следует проверять после запуска.

## Структура

| Путь | Назначение |
| --- | --- |
| `Example/DCP_PAGE.bin` | Исходный пример карты портов, 16 384 байта |
| `Example/DCP.xlsx` | Сопроводительная таблица Excel |
| `Example/sp2000.pdf` | Техническая документация Sprinter |
| `Example/внутренние_порты.txt` | Символические имена и описания внутренних кодов |
| `src/` | Точка входа приложения |
| `internal/dcp/` | Адресация, алиасы, документ и сохранение |
| `internal/bios/` | Генератор адресов и масок |
| `internal/catalog/` | Встроенный справочник внутренних кодов |
| `internal/ui/` | Интерфейс Fyne и проверки взаимодействий |
| `scripts/` | Нативная сборка Windows/Linux/macOS |
| `Build/` | Место для результатов сборки, исключённых из Git |
| `docs/` | Документация проекта и результаты исследования |

Файлы в `Example/` сохранены без изменений. Их размеры и SHA-256 приведены
в обзоре; бинарные материалы и исходный текст защищены настройками Git
от автоматического изменения переводов строк.

## Расширение

Вычислительные пакеты не зависят от GUI. В дальнейшем можно добавить сравнение
двух карт, пакетное редактирование, экспорт отчётов и CLI без изменения формата BIN.
Эти функции пока не реализованы. Приложение работает с файлами и не обращается
к BIOS или оборудованию Sprinter во время работы.
