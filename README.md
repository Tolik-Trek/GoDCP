# GoDCP

Проект приложения для работы с файлом карты портов DCP компьютера Sprinter 2000.

Цель: легковесное приложение с простой сборкой для основных настольных ОС —
Windows, Linux и macOS. Конкретные функции, интерфейс, язык программирования
и библиотеки будут определены после уточнения требований. Название проекта
пока не фиксирует выбор языка Go.

## Текущее состояние

Выполнена первичная инициализация репозитория и изучены исходные материалы.
Код приложения, зависимости и система сборки пока отсутствуют.

Результаты изучения файлов, проверенные свойства дампа и открытые вопросы
собраны в [обзоре исходных материалов](docs/INITIAL_SURVEY.md).

## Структура

| Путь | Назначение |
| --- | --- |
| `Example/DCP_PAGE.bin` | Исходный пример карты портов, 16 384 байта |
| `Example/DCP.xlsx` | Сопроводительная таблица Excel |
| `Example/sp2000.pdf` | Техническая документация Sprinter |
| `Example/внутренние_порты.txt` | Символические имена и описания внутренних кодов |
| `src/` | Место для исходного кода приложения |
| `Build/` | Место для результатов сборки, исключённых из Git |
| `docs/` | Документация проекта и результаты исследования |

Файлы в `Example/` сохранены без изменений. Их размеры и SHA-256 приведены
в обзоре; бинарные материалы и исходный текст защищены настройками Git
от автоматического изменения переводов строк.

## Следующий этап

После получения подробностей определить сценарии работы, правила редактирования
и сохранения карты, поддерживаемые варианты формата и требования к интерфейсу.
Затем выбрать технологию с учётом размера приложения и сложности сборки
на целевых ОС. Сверять адресацию с конкретной версией карты и конфигурации Sprinter.
