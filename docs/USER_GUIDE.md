# Работа с GoDCP

GoDCP работает с бинарной картой портов Sprinter 2000 размером 16 384 байта.
Откройте свой BIN либо `Example/DCP_PAGE.bin`. Версию и назначение файла
выбирает пользователь; приложение не сопоставляет его с версией прошивки.

Названия вкладок и команд зависят от выбранного языка интерфейса: русского
или английского. Нужные команды доступны в самом окне приложения.

## Сборка

Нужны Go, C-компилятор и графические зависимости Fyne. Для воспроизведения
текущей сборки используйте Go 1.27.x; минимальная версия языка указана
в `go.mod`. Скрипты собирают приложение для той ОС и архитектуры, на которой
запущены. Они не устанавливают пакеты и не меняют системные настройки.
Первой сборке нужен доступ к Go-модулям в сети.

В Windows установите GCC из MSYS2 и добавьте каталог выбранного компилятора
в PATH текущей консоли. Например, для стандартной установки UCRT64:

```powershell
$env:PATH = 'C:\msys64\ucrt64\bin;' + $env:PATH
.\scripts\build.ps1
```

Если Go отсутствует в PATH, можно передать путь явно:

```powershell
.\scripts\build.ps1 -Go 'C:\path\to\go\bin\go.exe'
```

Скрипт также распознаёт переносимую установку в
`%LOCALAPPDATA%\GoDCP-tools\go<версия>\go\bin\go.exe`.
Результат — `Build/GoDCP.exe`, без отдельного консольного окна.

В Linux нужны GCC и заголовки OpenGL/X11. Например, для Ubuntu/Debian:

```bash
sudo apt-get install gcc libgl1-mesa-dev xorg-dev
bash scripts/build.sh
```

В macOS установите Xcode Command Line Tools (`xcode-select --install`)
и запустите `bash scripts/build.sh`. В Linux и macOS получается исполняемый
файл `Build/GoDCP`. На macOS скрипт дополнительно создаёт приложение
`Build/GoDCP.app` с поддержкой High DPI. Это пакет без подписи разработчика
и без notarization; сборка и запуск на macOS в текущем Windows-окружении
не проверялись.
Путь к Go при необходимости задаётся как `GO=/path/to/go bash scripts/build.sh`.
Подробности настройки платформ доступны в [инструкции Fyne](https://docs.fyne.io/started/quick/).

Перед сборкой оба скрипта выполняют `go test ./...` и останавливаются при
ошибке. Для повторной сборки после отдельного запуска тестов доступны
`-SkipTests` в PowerShell и `--skip-tests` в Bash. Изменение `CGO_ENABLED`
ограничено запуском скрипта.

GitHub Actions настроен на сборку и тестирование Windows, Linux и macOS
с отдельными артефактами: EXE для Windows, архив бинарника для Linux
и архив `.app` для macOS. Наличие файла workflow само по себе не означает,
что облачная сборка уже прошла: результаты проверяются во вкладке Actions
после запуска в GitHub.

## Редактирование

Вкладка редактора показывает назначения в виде таблицы; HEX-режим позволяет
работать с байтами по смещениям `0000h–3FFFh`. В обоих представлениях меняется
один и тот же документ. Операции редактирования заменяют байты, сохраняя длину
карты. Выберите запись в таблице или байт в HEX, затем в боковой панели
задайте новое значение и нажмите «Заменить байт». Undo/Redo отменяет
и возвращает изменения. Массовое редактирование пока не реализовано.

При редактировании не путайте:

- **Внешний адрес** — адрес порта, к которому обращается программа Sprinter.
- **Смещение DCP** — позиция записи внутри BIN.
- **Внутренний код** — байт назначения, хранящийся в этой записи.

Одна запись относится сразу к 128 адресам-алиасам при фиксированных CNF,
направлении, DOS и PN5. У этих адресов совпадают значимые для DCP биты.
Следовательно, изменение байта затрагивает всю группу адресов.

Код `00h` отображается как отсутствие назначения. Код без имени в справочнике
сохраняется и редактируется так же, как известный. Имя порта — подсказка из
исходного текстового справочника, а не доказательство назначения в прошивке.

Сохранение записывает текущие 16 384 байта. Используйте «Сохранить как»,
если нужен отдельный выходной файл: сначала выберите папку, затем введите
имя файла. Для существующего файла появится подтверждение замены.
Поиск и списки уже до сохранения показывают текущие изменения.

## Списки и поиск

В редакторе таблицы, «Назначенных портах» и «По внутреннему порту» перед
строкой поиска можно выбрать поле: **Все поля**, **Адрес**, **Смещение**,
**Код** или **Имя**. Числа сравниваются точно; имена ищутся по части строки
без учёта регистра. Например, для единственной записи `0056` выберите
«Смещение», а для всей группы внешнего порта `204E` — «Адрес».
Поиск адреса понимает все 128 алиасов: `2046` и `204E` дают одну группу,
а в столбце «Адрес*» остаётся её минимальный представитель `2046`.

Числа по умолчанию шестнадцатеричные. Поддерживаются `204E`, `#204E`,
`0x204E`, `204Eh`, а также двоичная запись с `%`, например
`%0010'0000'0100'1110`. Диапазоны: адрес `0000–FFFF`, смещение `0000–3FFF`,
код `00–FF`. Некорректное число в выбранном числовом поле отмечается ошибкой
и не даёт результатов. В режиме «Все поля» число может одновременно
совпасть со смещением, адресом и кодом; выберите конкретное поле для
однозначного поиска. Частичные совпадения цифр внутри других чисел
не используются.

Условия CNF, I/O, DOS и PN5 применяются вместе с поиском. «Очистить»
сбрасывает только текст поиска; для снятия условий выберите «Все»
в соответствующих списках. Пустая строка или пробелы не ограничивают
результат. Вкладка «По внутреннему порту» дополнительно сохраняет ограничение
по коду из своего верхнего поля. Переключение языка сохраняет запросы и
выбранные поля. В HEX-режиме редактора используйте переход по смещению
в боковой панели; табличные фильтры в этом режиме скрыты.

**Назначенные внешние порты** — ненулевые записи загруженной карты.
Группа показывает внешний адрес, внутренний код и условия; раскройте алиасы,
чтобы увидеть все соответствующие внешние адреса. Список означает наличие
назначения, а не факт обращения к нему работающей программой.

**По внутреннему порту** — найдите все внешние назначения с заданным внутренним кодом.
Результаты сохраняют различие CNF, IN/OUT, DOS и PN5. Неизвестный код можно
искать числом.

**По внешнему порту** — введите 16-битный внешний адрес. Поиск рассматривает
все 32 сочетания условий: четыре CNF, два направления, два состояния DOS,
два PN5. У одного внешнего адреса назначения могут различаться между условиями.

В таблицах `/DOS=0` означает включённый DOS, `/DOS=1` — выключенный.
`IN` соответствует `/WR=1`, `OUT` — `/WR=0`. PN5 — отдельное условие выбора
записи; приложение не определяет его аппаратное состояние.

## Значения для BIOS

На вкладке генератора задайте внешний адрес, внутренний код и условия,
для которых нужно назначение. Результат содержит:

| Регистр | Содержимое |
| --- | --- |
| HL | Упакованный адрес DCP |
| DE | Маска: 1 фиксирует бит, 0 допускает оба значения |
| B | Внутренний код |

Числа выводятся в двоичной записи с `%` и разделителями `'`. Копируйте
литерал в свой исходник BIOS. Генератор не запускает функцию BIOS
и не применяет правило к открытому BIN.

Пример для `OUT 204Eh → C3h`, при любых CNF, DOS и PN5:

```text
HL = %00'000'0'0101'0110
DE = %00'001'1'1111'1111
B  = %1100'0011
```

Охват — 16 записей, поскольку направление зафиксировано, а остальные
режимы свободны. Это адреса и маска в пространстве DCP, а не двоичная запись
самого внешнего адреса `204Eh`.
