# GoDCP: устройство и границы первой версии

Согласованная концепция, 12 октября 2026 года. Стек: Go и Fyne.
Интерфейс рассчитан на плотную работу с таблицами, HEX и клавиатурой,
с русским и английским языками.

## Документ

Документ — загруженный бинарный файл ровно 16 384 байта: четыре карты
по 4096 записей. У него есть исходное и текущее содержимое, путь,
признак изменений и история Undo/Redo. Все вкладки анализа читают текущее
содержимое, включая несохранённые изменения.

Версия BIN — дело пользователя. Приложение не определяет версию BIOS или
FPGA и не проверяет совместимость с ними. Справочник — только подписи
и пояснения: он не создаёт назначения, не исправляет и не отбрасывает
неизвестные коды. Значения `18h`, `19h`, `1Ah` и любые другие байты допустимы.

Сохранение выдаёт только исходный формат BIN без заголовка, метаданных,
перестановки записей и изменения размера. Вставка и удаление байтов
не относятся к операциям редактора.

## Вкладки

| Вкладка | Задача |
| --- | --- |
| Редактор карты | Таблица назначений и дополнительный HEX-режим; изменение байта, Undo/Redo |
| Назначенные порты | Обзор ненулевых назначений с условиями действия и группами алиасов |
| По внутреннему порту | Все записи и внешние группы для выбранного внутреннего кода |
| По внешнему порту | Расшифровка внешнего адреса для всех 32 сочетаний режимов |
| Генератор BIOS | Расчёт копируемых двоичных значений HL, DE и B |

Слово «назначенные» означает наличие записи в карте. BIN не содержит сведений
о том, использует ли порт конкретная программа.

## Адресация и группы

Смещение в файле — 14-битный индекс. Внешний адрес — 16-битный адрес
процессора. Внутренний код — значение одного байта по вычисленному индексу.
Эти три числа показываются раздельно.

| Биты индекса | Значение |
| --- | --- |
| 0–2 | A0–A2 внешнего адреса |
| 3 | A7 |
| 4 | A13 |
| 5–6 | A5–A6 |
| 7–8 | A14–A15 |
| 9 | /WR: 0 = OUT, 1 = IN |
| 10 | /DOS: 0 = DOS включён, 1 = выключен |
| 11 | PN5 |
| 12–13 | CNF0–CNF3 |

A3, A4 и A8–A12 не участвуют в индексе. Поэтому каждой записи при
фиксированных режимах соответствуют 128 внешних адресов. Таблицы сначала
показывают группу с минимальным представительным адресом, затем позволяют
раскрыть адреса и маску значимых битов. Изменение записи меняет всю группу.

Полный контекст — 4 CNF × 2 направления × 2 состояния /DOS × 2 PN5 = 32
сочетания. Поиск внешнего адреса раскрывает именно эти условия, а не выбирает
произвольное «основное» назначение. Нулевой код означает отсутствие назначения
в данной записи карты; это не утверждение обо всех аппаратных портах компьютера.

## Генератор BIOS

Генератор использует контракт `DCP_CONFIG` из `SP_Core/bios/exp/DCP.ASM`:
HL — адрес DCP, DE — маска, B — внутренний код. В маске 1 фиксирует бит,
0 разрешает оба значения. Генератор не вызывает BIOS и не изменяет BIN.

Выход — поле текста, из которого можно копировать значения. Литералы
записываются с `%` и разделителями `'`, как в таблице первичной инициализации
страницы `40h`. Дополнительное представление — `DW`, `DW`, `DB`;
шаблоны вызова BIOS в первую версию не входят.

Условия «любое» превращаются в нули маски. Если выбранный набор условий
невозможно выразить одной маской без лишних записей, необходимо сформировать
несколько точных правил. Для каждого правила показывается охват записей.
При расширении генератора это правило важнее минимального числа строк.

Контрольный пример: `OUT 204Eh → C3h`, любые CNF, DOS и PN5:

```text
HL = %00'000'0'0101'0110
DE = %00'001'1'1111'1111
B  = %1100'0011
```

Он охватывает 16 записей карты и не фиксирует старшие два неиспользуемых
бита 16-битных регистров.

## Разделение ответственности

Вычисления адресации, генерация и история документа отделены от Fyne.
Таблицы поиска используют эти операции и читают текущие байты документа.
Это позволяет тестировать преобразования без графической среды и позднее
использовать те же операции в консольном инструменте.

Справочник встроен в приложение как JSON, полученный из активных однобайтовых
`EQU` в `Example/внутренние_порты.txt`. Он сохраняет исходные имена, комментарии
и их неопределённость. Закомментированные `reserved` и многобайтовые константы
загрузчика не становятся именами портов. Пользовательский справочник,
сравнение двух BIN, экспорт результатов и пакетное редактирование — возможные
следующие расширения, не обязательные условия первого запуска.

## Проверка

Адресация проверяется на всех индексах и адресах, с отдельными примерами
из PDF, XLSX и BIN. Маски генератора проверяются по фактически охватываемому
набору индексов. Документ проверяется на точный размер, сохранение неизвестных
байтов, Undo/Redo и побайтовый цикл открыть/сохранить.

Сборка и запуск GUI проверяются отдельно от вычислительного ядра. Успешная
сборка для одной ОС не означает проверки двух других; тесты модели не означают
проверку BIOS на реальном Sprinter.
