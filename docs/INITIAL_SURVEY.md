## Адресация по документации

В PDF, §13.1, страницы 27–28, описана страница ОЗУ `40h`, содержащая четыре
карты по 4096 однобайтовых назначений. Её общий размер совпадает с размером
предоставленного бинарного файла. Номера страниц PDF совпадают с печатными.

Внешний 16-битный адрес порта преобразуется в смещение следующим образом.
Здесь `P` — биты адреса порта процессора, `offset` — смещение в полном дампе.

| Бит `offset` | Источник | Значение |
| --- | --- | --- |
| 0, 1, 2 | P0, P1, P2 | Младшие биты адреса |
| 3 | P7 | Бит адреса |
| 4 | P13 | Бит адреса |
| 5, 6 | P5, P6 | Биты адреса |
| 7, 8 | P14, P15 | Биты адреса |
| 9 | `/WR` | 0 — OUT, 1 — IN |
| 10 | `/DOS` | 0 — DOS включён, 1 — выключен |
| 11 | PN5 | В документации связан с блокировкой порта Pentagon; может отсутствовать в отдельных конфигурациях |
| 12, 13 | Номер карты | 0–3 |

P3, P4 и P8–P12 не участвуют в выборе записи: несколько внешних адресов
могут ссылаться на один байт. Пример из PDF: `0050h` и `0058h`.
Чтение и запись одного адреса могут иметь разные назначения.

Для будущей реализации необходимо различать внешний адрес порта, смещение
в файле и однобайтовый внутренний код, прочитанный по этому смещению.
Номер карты, направление и режимы являются частью адресации.

## Таблица Excel

На `Лист1` находятся формулы преобразования адресов и элементы управления:

- `I9:V10` описывает ту же перестановку битов, что PDF; старшие поля подписаны
  `cnf`, `cnf`, `pn5`, `dos`, `wr/rd`.
- `G20`, `G22`, `G23` связаны с переключателями направления, DOS и PN5.
  Список `I20:I23` содержит `CNF_0`–`CNF_3`, индекс выбора хранится в `J20`
  с нумерацией от единицы.
- Сохранённый пример: `E4 = 7786h`, карта 0, `/WR=1`, `/DOS=1`, `PN5=0`;
  результат `E10 = 069Eh`
  (`F10 = 1694`); минимальный адрес с тем же набором значимых битов —
  `E12 = 6086h` (`F12 = 24710`).
- `B11:C18` подписан «Смещения для OUT (number),A», однако формулы сохраняют
  выбранное направление и перебирают восемь сочетаний P13–P15. В сохранённом
  состоянии `/WR=1`, то есть по таблице PDF это смещения чтения:
  `060E`, `061E`, `068E`, `069E`, `070E`, `071E`, `078E`, `079E`.
  Все эти смещения в каждом из четырёх блоков предоставленного дампа
  содержат `00h`.
- Обратный пример: `E15 = 46Dh`, `E17 = 00E5h`. По смещениям
  `046D`, `146D`, `246D`, `346D` в дампе находятся `C0`, `C0`, `C1`, `C0`.

На `Лист1` 76 формульных ячеек; на `Лист2` 7 формульных ячеек с отдельными
арифметическими расчётами без достаточных пояснений об их назначении.
Полной таблицы 16 384 назначений в книге нет. Содержимое проверено чтением
книги и XML формул, включая общие формулы Excel; оригинал не пересохранялся.

## Проверенные свойства бинарного примера

Файл содержит 51 различное байтовое значение: 12 480 нулевых и 3904 ненулевых
байта. Разделение на четыре блока по размеру из документации даёт:

| Номер блока | Смещения | Ненулевых байтов |
| --- | --- | ---: |
| 0 | `0000h–0FFFh` | 1232 |
| 1 | `1000h–1FFFh` | 740 |
| 2 | `2000h–2FFFh` | 756 |
| 3 | `3000h–3FFFh` | 1176 |

Все четыре блока различаются. Примеры для карты 0, DOS включён, PN5=0,
при применении адресации из PDF:

| Обращение | Смещение | Байт | Имя в текстовом справочнике |
| --- | --- | --- | --- |
| OUT `204Eh` | `0056h` | `C3h` | `ALL_MODE`, строка 218 |
| IN `204Eh` | `0256h` | `00h` | Нет назначения в этом дампе |
| OUT `FFFDh` | `01FDh` | `90h` | `AY_FFFD_WRITE`, строка 167 |
| IN `FFFDh` | `03FDh` | `52h` | `AY_FFFD_READ`, строка 104 |
| OUT `BFFDh` | `017Dh` | `91h` | `AY_BFFD`, строка 168 |

Это результаты чтения конкретного файла и применения документированной
формулы. Они не подтверждают поведение иной версии BIOS/FPGA или работающего
компьютера. В частности, ноль в примере IN `204Eh` нельзя переносить на
другие версии карты.

## Ограничения и расхождения источников

- PDF на страницах 30–31 явно помечает каталог внутренних кодов как
  «для sp-97». Версия руководства сама по себе не определяет актуальный
  набор кодов предоставленного дампа.
- На странице 29 комментарии примера `OPEN_PORT` переставляют чтение и запись
  относительно таблицы сигналов и объяснения на странице 28. Здесь направление
  указано по странице 28; его соответствие целевой конфигурации предстоит
  подтвердить при реализации.
- Текстовый справочник прямо сообщает о частично неразобранных портах Sp97
  (строка 14), содержит `reserved`, `UNKNOWN` и комментарии с вопросами.
- Коды `18h`, `19h`, `1Ah` встречаются в дампе по четыре раза каждый,
  хотя в текстовом справочнике строки 43–45 помечены `reserved`.
  Неизвестный код нельзя автоматически считать ошибкой или заменять нулём.
- В руководстве нулевая запись означает отсутствие назначенного внешнего
  порта; встроенные порты Z84C15 имеют отдельную логику (страница 28).
