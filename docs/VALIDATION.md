# Проверка приложения

Дата: 12 октября 2026 года. Версия приложения: 0.1.1.

## Проверено на Windows amd64

- Go 1.27.2, GCC 16.2.0 из MSYS2 MINGW64, Fyne 2.8.1.
- `go test ./... -count=1`: тесты всех пакетов — успешно.
- `scripts/build.ps1 -SkipTests`: сборка после отдельного прогона тестов — успешно.
- `go mod verify`: все модули проверены. Проверка checksum database при
  загрузке зависимостей оставалась включённой.
- `Build/GoDCP.exe --version`: код выхода 0, вывод `GoDCP 0.1.1`.
- Размер EXE: 25 584 640 байт. SHA-256:
  `431C301D23B910DC63DA3747F8BB0266D2F7B1FC3F59A1F6A5298C9D05580245`.
- Прямые импорты EXE: GDI32, KERNEL32, msvcrt, OPENGL32, SHELL32, USER32.
  Дополнительных DLL MSYS2 в таблице импортов нет.
- SHA-256 всех четырёх файлов `Example/` совпадают с первоначальным обзором.

## Проверки поведения

- Все 16 384 смещения, все 65 536 внешних адресов во всех 32 контекстах
  проверены по независимой таблице адресных битов.
- Проверены 512 групп по 128 алиасов и известные байты примера.
- Маски BIOS проверены на всех 405 непустых сочетаниях условий; наборы
  охваченных записей точны и не пересекаются.
- Проверены точное сохранение BIN, неизвестные коды, Undo/Redo и сохранение
  исходного файла при реальном отказе замены на Windows.
- GUI-тесты используют программный драйвер Fyne: открытие BIN, поиск,
  изменение байтов, Undo/Redo, обновление представлений, копирование результатов,
  сохранение состояния при смене языка и запрет копирования устаревшего расчёта.
- Отдельные регрессии покрывают синхронизацию выделения Table/HEX,
  поиск неканонических адресов и геометрию после смены языка/режима.
- Проверен поиск по отдельным полям в редакторе, назначенных портах и
  внутреннем поиске: смещение `0056` даёт одну запись, адреса `2046`/`204E`
  дают одинаковые группы; код и имя не совпадают с чужими столбцами.
- Числовые запросы больше не совпадают с подстроками других чисел
  (например, `C3` со смещением `0C34`). Проверены HEX и двоичные формы,
  ограничения разрядности, ошибочный ввод и очистка, сохранение полей/запросов
  при смене RU/EN и совместное применение условий CNF, I/O, DOS, PN5.
- Отдельные GUI-тесты прямого поиска проверяют внутренние коды, точные имена,
  неизвестные коды, нулевые записи, все 32 контекста внешнего адреса и
  отключение действий для старого результата после ошибочного ввода.
- Заново созданы 12 программно отрисованных изображений пяти вкладок и HEX
  на двух языках. Визуально проверены изменённые панели фильтров:
  назначенные порты и внутренний поиск на русском, редактор на английском.

Для повторного создания изображений в `Build/`:

```powershell
$env:GODCP_SCREENSHOT = '1'
go test ./internal/ui -count=1
Remove-Item Env:GODCP_SCREENSHOT
```

## Границы проверки

Программная отрисовка и тесты GUI не являются ручной проверкой настоящего
окна с драйвером OpenGL. Выполненный запуск EXE проверял путь `--version`.
Потребление памяти и время интерактивного запуска пока не измерялись.

Скрипты Linux/macOS и workflow подготовлены. Проверены синтаксис Bash
и XML шаблона macOS Info.plist, но сборки на этих ОС и облачный CI
в этой сессии не запускались. macOS-пакет создаётся без подписи и notarization.

Сравнение двух карт, пакетное редактирование, экспорт отчётов и CLI-операции
с картой остаются следующими расширениями. BIOS и аппаратный Sprinter
не исполнялись: приложение работает только с файлом и расчётами.
